# Road sign artwork

The SVG files in this folder come from the **SADC road sign** set on Wikimedia Commons
(https://commons.wikimedia.org/wiki/Category:SADC_road_signs). Every file was checked as
**public domain** on Wikimedia Commons when it was imported (October 2026).

File names match the official sign number in the SADC Road Traffic Signs Manual
(SADC-RTSM / SARTSM), e.g. `R1.svg` = Stop, `W332.svg` = Speed hump ahead.
Sign names and meanings shown in the app live in `lib/data/signs.ts`.
